# Orbit Beyond Private Limited — website

Website for Orbit Beyond Private Limited (India). Built by Zuno Design Studios.

- Static site, no build step: HTML pages are generated by `build_pages.py` (edit page bodies there, bump `VER` to cache-bust css/js, run `python build_pages.py`).
- Home page is a scroll-driven WebGL lunar surface (`js/surface.js`); terrain maps are produced by `tools/make_terrain.py` into `assets/moon/`.
- Live on AWS: S3 bucket `orbitbeyond-india-site-prod` + CloudFront `ERHGFZ5GKBO7Z` (us-east-1). Every push to `main` deploys via `.github/workflows/deploy.yml` (needs repo secrets `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`).
- Review preview: Vercel project `orbit-beyond-india`.
